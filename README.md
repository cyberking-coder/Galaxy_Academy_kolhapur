# Galaxy Academy — गॅलेक्सी अकॅडमी

An award-worthy, animated one-page website for **Galaxy Academy**, a coaching center in Mangalwar Peth, Kolhapur, Maharashtra.

Rated **4.9 ★ (210+ reviews)** — coaching for 11th & 12th Science, NEET, JEE and Diploma classes.

## Features
- Cosmic "galaxy" theme with animated starfield, orbiting rings and cursor glow
- Scroll-reveal animations and animated count-up stats
- Course cards with interactive spotlight hover
- Real student reviews, Google Maps embed, click-to-call
- Fully responsive with a mobile menu

## Run
Just open `index.html` in a browser — no build step. Or serve locally:

```bash
python3 -m http.server 8000
```

## Files
- `index.html` — markup and content
- `styles.css` — theme, layout and animations
- `script.js` — starfield, reveals, count-up, interactions
